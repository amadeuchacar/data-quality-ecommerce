# Documentation — Olist E-Commerce Data Quality

Study material for the project: the theory of **Data Quality Fundamentals** (Moses, Gavish and Vorwerck, O'Reilly), what each part of the code does, why it exists, why it was built that way, and how to run, test and simulate incidents.

| Chapter | Content |

| [2. Theoretical foundations](02-theoretical-foundations.md) | Data downtime, contracts, circuit breaker, DAMA, the five pillars, anomaly detection, SLA/SLI/SLO, incidents, lineage, certification and maturity, each linked to the code |
| [3. Architecture](03-architecture.md) | Layers, modules, the 17 architecture decisions with their reasons and accepted costs, and production alternatives |
| [4. Code reference](04-code-reference.md) | Every module: functions, parameters, returns, outputs and implementation decisions |
| [5. Configuration](05-configuration.md) | Every YAML key and recipes for common changes |
| [6. Running and testing](06-running-and-testing.md) | How to run, where outputs go, tests, incident simulation with real results, the incident CLI and common problems |
| [7. Study guide](07-study-guide.md) | Reading path, glossary, known limitations, review questions and exercises |

**Quick start:** read chapter 1, run the walkthrough in [6.5](06-running-and-testing.md#65-simulating-incidents), and come back to chapters 2 and 3 with the results in hand.
