# Documentation / Documentação

Complete study material for the **Olist E-Commerce Data Quality** project: the theory of *Data Quality Fundamentals* (O'Reilly) applied to the code, the architecture decisions and their reasons, a reference of every module, and how to run, test and simulate incidents.

Material de estudo completo do projeto **Qualidade de Dados no E-Commerce Olist**: a teoria do livro *Data Quality Fundamentals* (O'Reilly) aplicada ao código, as decisões de arquitetura e suas justificativas, a referência de cada módulo e como executar, testar e simular incidentes.
